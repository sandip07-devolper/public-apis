## ✨ Why this directory

- **Fast to scan.** One clean table per category with auth, HTTPS and CORS at a glance.
- **Searchable.** A live site with instant search and filters, hosted free on GitHub Pages.
- **Agent ready.** A dedicated list of MCP servers for Claude, Cursor and VS Code.
- **Community driven.** Every entry is a pull request away.

## 🧭 How to read the tables

| Symbol | Meaning |
|:--:|:--|
| 🔓 | No authentication required |
| 🔑 | API key required |
| 🪪 | OAuth required |
| ✅ / ❌ / ❔ | Supported / not supported / unknown (HTTPS and CORS) |
