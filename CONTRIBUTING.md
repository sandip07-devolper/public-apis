# Contributing

Thanks for helping keep this directory useful.

## Add an API

1. Open the file for the category in `apis/`.
2. Add one row in **alphabetical order**:

   `| [**Name**](https://link) | Short description (under 100 characters) | 🔓 None | ✅ | ✅ |`

3. Auth is one of `🔓 None`, `🔑 Key`, `🪪 OAuth`. HTTPS and CORS are `✅`, `❌` or `❔`.
4. The API must be free to use, at least in part, and have working documentation.
5. Open a pull request with a short title such as `Add Open-Meteo`.

## Rules

- One API per row. No duplicates.
- No link shorteners or affiliate links.
- Keep descriptions neutral and factual.
